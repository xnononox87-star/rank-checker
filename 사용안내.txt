HGG 키워드 순위 확인 프로그램 - 사용 안내
==========================================

[처음 한 번만 하는 설치]

1) 파이썬 설치
   - python.org 접속 → 상단 Downloads → "Download Python 3.x" 버튼으로 설치파일 받기
   - 설치 첫 화면 맨 아래 "Add python.exe to PATH" 에 꼭 체크 → Install Now
   - 설치가 끝나면 컴퓨터를 한 번 다시 시작하면 좋아요.

2) 이 폴더(rank_checker)를 바탕화면 등 편한 곳에 압축 풀기

3) install.bat 더블클릭
   - "Windows의 PC 보호" 파란 창이 뜨면 → 추가 정보 → 실행
   - 검은 창에서 설치가 진행돼요(몇 분). "DONE!"이 나오면 아무 키나 눌러 닫기
   - 크롬(Chrome)이 컴퓨터에 설치돼 있어야 쿠팡 확인이 돼요.

[실행]

4) run.bat 더블클릭 → 몇 초 뒤 브라우저에 프로그램 화면이 열려요 (주소: http://localhost:8501)
   - 검은 창은 프로그램이 켜져 있는 동안 닫지 마세요. 끝낼 때 검은 창을 닫으면 돼요.

[자동 업데이트]

- run.bat 을 켤 때마다 최신 버전을 자동으로 받아요. 다시 다운받아 설치할 필요 없어요.
- 켜져 있는 중에는 화면 왼쪽 [🔄 업데이트 확인] 버튼을 누르면 바로 반영돼요.
- 키·설정(config.json)과 지난 기록(data 폴더)은 업데이트해도 그대로 남아요.

[처음 한 번만 하는 설정 - 프로그램의 "설정" 탭]

5) 네이버 검색광고 API 키 (광고 성과용, 무료)
   - searchad.naver.com 로그인(홍고고 계정) → 광고시스템 → 상단 메뉴 "도구" → "API 사용 관리"
   - "네이버 검색광고 API 서비스 신청" → 발급된 "액세스라이선스"와 "비밀키" 복사
   - 프로그램 설정 탭에 붙여넣기 → 저장
   - CUSTOMER_ID 는 미리 넣어 두었어요.
   ※ 비밀번호는 프로그램에 넣지 않아요. 키만 있으면 로그인 없이 광고 데이터를 불러와요.

6) 우리 상품 찾는 기준 확인
   - 네이버 스토어 이름: 검색 결과 오른쪽에 보이는 우리 판매처 이름(지금은 "HGG"로 넣어둠)
   - 상품명 브랜드: HGG테크, 가드랩 (상품명에 이 단어가 있으면 우리 상품으로 봐요)
   - 쿠팡 상품번호: 쿠팡에서 우리 상품 페이지를 열면 주소가
     coupang.com/vp/products/1234567890 처럼 나와요. 이 숫자를 한 줄에 하나씩 넣어 주세요.
     (상품명에 HGG테크/가드랩이 없는 쿠팡 상품은 번호를 넣어야 찾을 수 있어요)

[네이버 자동 확인 - 웨일 확장 프로그램 설치 (처음 한 번만)]

- 웨일 주소창에 whale://extensions 입력 → 엔터
- 오른쪽 위 "개발자 모드" 켜기
- "압축해제된 확장 프로그램을 로드합니다" 클릭 → rank_checker 폴더 안의 naver_extension 폴더 선택
- 웨일 오른쪽 위 퍼즐 아이콘 → "HGG 네이버 순위 확인" 옆 핀 눌러 고정
- 사용: run.bat 켜기 → 웨일의 HGG 아이콘 클릭 → [네이버 순위 확인 시작]
  → 끝나면 순위 프로그램 화면에 자동으로 반영 (안 되면 [네이버 결과 불러오기])
- 확장 프로그램이 업데이트되면 whale://extensions 에서 HGG 네이버 순위 확인의 새로고침(↻) 버튼을 한 번 눌러 주세요.

[사용법]

- 순위 확인 탭: 키워드 고르고 [순위 확인 시작]
  · 초록 "상단" = 1페이지 10위 이내 (설정에서 기준 변경 가능)
  · 노랑 "1페이지 하단" / 빨강 "1페이지 없음"
  · 같은 상품을 여러 개 등록했으면 "4위, 5위, 8위"처럼 모두 보여요
  · 지난번보다 올랐는지/내렸는지도 같이 보여요
- 네이버 광고 탭: 기간 고르고 [불러오기] → 상품별 노출·클릭·클릭률·입찰가·광고비
- 자료 넣기 탭: 광고 리포트 엑셀(네이버/쿠팡), 검색결과 캡처를 끌어다 놓기
  · 검색결과 화면을 Ctrl+A → Ctrl+C 해서 붙여넣으면 캡처보다 정확해요

[주의]

- 순위 확인 때는 크롬 창이 따로 열려서 저절로 검색해요. 끝날 때까지 그 창은 건드리지 마세요.
  이 창은 로그인하지 않은 전용 창이라 판매자 계정과 연결되지 않아요.
  쿠팡은 자동 검색을 막을 수 있으니 하루 1~2번만 돌려 주세요. 막히면 "확인 불가"로 표시돼요.
- 네이버 쇼핑 검색 API는 2026년 7월에 종료돼서, 네이버도 쿠팡처럼 크롬 창으로 확인해요.
  순위는 광고 자리를 포함한 실제 화면 순서예요. 보안문자가 뜨면 그 창에서 직접 풀어 주세요(90초 기다려요).
- API 키는 이 폴더의 config.json 파일에만 저장돼요. 이 파일은 다른 사람에게 보내지 마세요.
